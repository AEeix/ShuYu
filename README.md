# 《数域》M0 雏形

TapTap 聚光灯 Game Jam（主题「涌现」）数学卡牌肉鸽的最小可玩核心。
由 Claude 搭（2026-10-07），Unity 2022.3 LTS（中国区渠道版）。

## 怎么运行

1. 打开 Unity Hub →「Add」→ 选择本文件夹 `F:\Game project\ShuYu`
2. 用 Unity 2022.3 打开（首次会生成 Library 等，稍等片刻）
3. **无需场景**：直接点 Play
4. 点「开始游戏」进入对局

> 若 Hub 里没列出 2022.3 版本，检查 `D:\Unity\Editor` 下是否已装 `2022.3.62f3c1`。

## 现在能玩什么（M0 范围）

- 标题界面（深蓝黑底 + 金色标题 + 开始按钮）
- 4×4 棋盘 + 1 只小怪（初始 6）
- 3 张基础卡：`-1` / `-2` / `-3`（单格减法）
- 血条（初始 20）、每回合 3 次出牌、结束回合按钮
- 核心循环：出牌压数字 → 结束回合 → 数字 +1 增殖 → ≥10 溢出扣血并消失 → 判胜负

**玩法**：点一张卡，再点棋盘上的数字出牌。把数字压到 0 就赢；数字 ≥10 会溢出扣血，血 ≤0 就输。

**演示溢出**：故意不把小怪打死，点「结束回合」，看它每回合 +1，到 10 爆掉扣血。
（把 `GameConfig.InitialEnemyValue` 改成 8 或 9 能更快看到溢出）

## 代码结构

```
Assets/Scripts/
├── Core/
│   ├── GameConfig.cs    — 常量 + 色板 + 数值→颜色映射
│   ├── GameTypes.cs     — 枚举 + 数据模型（NumberData/CardData/BoardState/PlayerState）+ 运算规则
│   └── TurnManager.cs   — 回合状态机（出牌/增殖/溢出/判胜负，纯逻辑不碰 UI）
├── GameManager.cs       — 顶层管理器（标题↔对局切换，持有一局逻辑）
├── UIFactory.cs         — 程序化 UI 工厂（零手绘）
├── TitleScreen.cs       — 标题界面
└── BattleScreen.cs      — 对局界面
```
